## 1. 決定事項

### 商標・市場
- 「生成AIパスポート」は**登録商標**(第6768938号、区分09/16/41/42、権利者はGUGA)と判明。
  ただし App Store(日本)に同名を使う競合アプリが**27本**既に存在し、多くが
  「非公式です」の免責文一本で運用している。GUGAへの許諾取得は行わず、
  同じ運用方針(免責文の掲載)で進める判断とした。免責文3点セットは
  [appstore-listing.md](appstore-listing.md) に記載。
- 市場調査の結果、**有料枠は弱い**(最上位の有料アプリでも評価15件、無料上位は500件超)。
  価格は¥600、カテゴリは教育とした。売れ行きが悪ければ無料+課金や別資格への
  横展開も選択肢として残す。

### アプリ名・アイコン
- App Store掲載名: `生成AIパスポート 模試と500問｜全問解説`。ホーム画面表示名は
  別途 `AIパスポート`(3ファイルで統一が必要、[appstore-listing.md](appstore-listing.md) 参照)。
- アイコンは「合格スタンプ」(パスポートのスタンプ風、円形+「AI」+「生成AI パスポート」の
  文字)のデザインで確定。文字なし案も提示したが、検索結果での視認性を優先して
  文字ありを選択(ユーザー判断)。生成は `scripts/make-icons.py` に一本化。

### 技術構成
- 章立ては**5章のまま**(競合の「8章」表記は独自分割と判明、変更不要)。
- iOSアプリ化は **Capacitor 8**(Swift Package Manager、CocoaPodsではない)を採用。
  **iPhone専用・縦向き固定**(iPadは非対応、横向きも非対応)。
  Bundle ID `com.hk5150.genaipassport` は**提出後に変更不可**なので確定値として扱う。
- ソースはリポジトリ直下に置いたまま(`src/`などへ移動していない)。`www/` は
  `scripts/sync-www.mjs` が生成するCapacitor用ビルド出力で、gitignore対象。
- 永続化は環境で分岐: Web版は`localStorage`、iOS版は`@capacitor/preferences`
  (`nativePlugin()`ヘルパーで抽象化)。
- Service WorkerはWeb/PWA版のみで有効。ネイティブ版では意図的に無効化
  (キャッシュ関連の不具合を避けるため)。
