## ホーム画面の表示名(アプリ名とは別物)

App Store の掲載名(30字)と、端末ホーム画面の表示名(`CFBundleDisplayName`)は**別フィールド**。
ホーム画面は約12文字で切れるため、掲載名をそのまま使うと「生成AIパスポー...」になる。

```
AIパスポート
```

`manifest.json` の `short_name`、`index.html` の `apple-mobile-web-app-title`、
`ios/App/App/Info.plist` の `CFBundleDisplayName` の3か所が同じ値。**変更時は3か所とも揃える。**

## 品質: JSダイアログのボタンが英語(未対応)

`confirm()`(「セッションを中断してホームに戻りますか？」)のボタンが **`Cancel` / `Ok`** と英語で出る。
本文は日本語なので、全体が日本語のUIの中でここだけ浮いて未完成に見える。有料アプリとしては直したい。

原因はWKWebViewのJSダイアログをネイティブ側が描画しており、そのボタン名がアプリのローカライズ設定に従うため。
対応案は2つ:

1. アプリに日本語ローカライズ(`ja.lproj`)を追加する — 小さいが、Capacitorがボタン名をハードコードしている場合は効かない
2. `confirm()`/`alert()` をアプリ内の自前ダイアログに置き換える — 確実だが実装量は増える

2026-08-16時点では未対応。申請前に片付ける。
